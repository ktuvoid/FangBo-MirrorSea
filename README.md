# Fangbo Jinghai (方泊 鏡海)

**Psychological Counseling & Mindful Drawing Space**

Official website: [https://jingha.dpdns.org/](https://jingha.dpdns.org/)

---

## 🪶Origin Story

At midnight, lacking inspiration for a homework topic, I brainstormed with my younger brother and started a small tool. Originally, it was created to meet the need for non-verbal expression tools during psychological counseling and guidance processes. Gradually, it evolved into a platform for communication and interaction between counselors and users.
